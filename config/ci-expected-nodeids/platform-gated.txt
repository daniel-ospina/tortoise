# tests/test_markers.py::PLATFORM_GATED_TESTS enumerates platform-gated files by
# SCANNING SOURCE. Ten review cycles showed a source scan cannot close that class
# (a new spelling is always possible), so this file asserts the property at
# RUNTIME instead, in two halves:
#   * COLLECTION — the file's tests must still be collected in the lane that runs
#     it; a skip is still a <testcase>, so a gate that hides a test from
#     collection removes it from the junit and reds here, whatever its spelling.
#   * OUTCOME — a test that is collected and then SKIPPED never ran, and a
#     test-level `if …: pytest.skip(…)` is exactly the shape the source scanner
#     loses. The allowance below is how many skips this file may legitimately
#     absorb off darwin; anything above it reds and names the nodeids.

#   On a darwin dev machine both tests RUN, which is within this budget (0 <= 2).
