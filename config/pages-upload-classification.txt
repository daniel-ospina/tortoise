# WHY THIS FILE EXISTS
# --------------------
# `wrangler pages deploy .` uploaded EVERY file under `website/`, and
# `.wranglerignore` is not honoured by the Pages upload path at all (hardcoded
# IGNORE_LIST, no ignore-file read — verified four ways in #3620). The deploy
# step now stages a DENYLIST copy, which means a NEW top-level entry is uploaded
# unless it is excluded. `tools/check_pages_upload_root.py` runs BEFORE the
# upload in the deploy job and fails if any tracked top-level entry is missing
# from this table — so an unclassified entry cannot reach the public internet on
# a green deploy. (The nested rules — `node_modules/` and `*.md` at any depth,
# plus the excluded directories' contents — remain in the deploy step; this table
# decides the top level, which is where the denylist's residual risk lives.)
#
# `admin/` is deliberately ABSENT: it used to be generated into `website/` by the
# blog-admin build step immediately before the deploy. #4171 moved the console to
# the app origin (`tortoise-dashboard`), which stages it into
# `website/apps/dashboard/dist/admin/` instead — so no `admin/` tree is produced
# under `website/` at all now.
#
