# #4068 — Reaper pass-2 discovery: scope the census to the ephemeral namespace

> ⚠️ **SUPERSEDED IN PART — see `## Outcome notes (post code-review)` below.** The plan body
> below says `--full-scan` is "detect-only" and that "every destruction path" requires
> `_is_ephemeral_dir`. Code review showed that is **false for the kill verb** (`reap()`'s `_kill`
> has no ephemerality gate; only the post-kill cleanup does), and that `_find_socket_dirs` was

> them before relying on any claim in the body.

> **For Pi:** Use `executing-plans` to implement this plan task-by-task.

**Goal:** Replace the two `find $TMPDIR` subprocess walks in `tortoise/embedded_reaper.py` with one in-process, namespace-scoped `os.scandir` primitive, preserving every kill/`rmtree` guard and adding a detect-only `--full-scan` escape hatch.

**Team:** organisation-design-team
**Role:** product-implementer

**Architecture:** `discover()` pass 2 currently shells out to `find $TMPDIR -maxdepth 2 ( -name redis.socket -o -name redis.pid )` — 16–24.6 s of metadata I/O on a churned macOS tempdir, exceeding its own `SOCKET_WALK_TIMEOUT` and then silently returning `[]`. The new primitive `_iter_candidate_dirs(tmpdir, *, predicate, deadline=None) -> _ScanResult` does a depth-1 `os.scandir`, **skips symlinked entries** (exact parity with `find` without `-L`, which does not descend them), tests `entry.name` **before any `stat()`**, and stops at an absolute monotonic deadline with a loud partial result. `_find_socket_dirs` (socket markers) and `_sweep_quarantine_dirs` (quarantine suffix) become its two consumers. Discovery is scoped to `EPHEMERAL_PREFIXES` — provably the same set every destruction path already requires at depth 1 — with `full_scan=True` broadening **enumeration only**.

## Design decisions (locked)

1. **Discovery predicate** = `name.startswith(EPHEMERAL_PREFIXES)` (or all names when `full_scan`). **Not** `_AUTOGEN_DIRNAME`, **not** `tempfile.gettempprefix()` (its 8-char suffix is private CPython internals). `_AUTOGEN_DIRNAME` stays attached to the classifier (`:1249`, `:1318`).
2. **Symlinked depth-1 entries are skipped** (`entry.is_symlink()`), preserving exact parity with `find` without `-L` (which does not descend a symlinked dir). This *eliminates* the only new discovery surface rather than defending it. The symlinked-marker-**file** case (a symlink named `redis.socket` inside a real ephemeral dir) is still discovered, matching `find -name`; a *dangling* marker symlink is dropped by `os.path.exists` in both the new code and the existing caller (`:1088`), so no behavioral divergence.
3. **Budget encoding** unifies with the module's existing convention: an **absolute** `deadline: float | None` (monotonic), like `reap(..., deadline=)` / `_run_sweep(..., deadline=)`. The deadline is checked **every iteration** (a `time.monotonic()` call is ~50 ns — negligible against a `scandir` step), so an already-expired deadline always yields `complete=False` + WARNING even on a tiny tree. No private exception — the primitive returns a result object, so a third caller cannot leak an exception.
4. **Truncation is visible to consumers** via `_ScanAwareList` — a `list` subclass carrying a `complete: bool` attribute whose **default is `False`** (fail-closed: a construction path that forgets to set it must not read as complete). `discover()` and `_run_sweep()` return it; every existing caller (`len()`, iteration, `== []`, `isinstance(x, list)`) keeps working. `_run_sweep` reads completeness as `getattr(records, "complete", True)` (the four tests that monkeypatch `discover` with `lambda jobs=1: [...]` return a plain list — `getattr`'s `True` default keeps them green) and forwards `full_scan` **only when True** (`discover(jobs=jobs, full_scan=True) if full_scan else discover(jobs=jobs)`), so those one-keyword lambdas are never passed an unexpected kwarg. `main()` prints `SCAN TRUNCATED` in the `[reaper] sweep complete:` summary.
   *Recorded limitations:* (a) `--json`'s contract is a **top-level array** (pinned by `test_cli_json_emits_stale_socket_shape`), so truncation is **not** added to it — the summary line and the `WARNING` log are the visibility; (b) `tests/conftest.py`'s end-sweep loop breaks on `not acted or deadline` (a truncated discovery there leaves residue until the next sweep — unreachable in practice with a 20 s budget against a ~0.7 s scoped scan); (c) `_sweep_quarantine_dirs`'s own scan truncation is **WARNING-only** — it is not OR'd into the summary.
5. **Env truthiness:** local `_env_truthy(raw)` accepting `{"1","true","yes","on"}` (case-insensitive), documented as mirroring the repo's de-facto standard; precedence `--full-scan` (True when passed) > env > `False`. No `--no-full-scan`.
6. **Marker vocabulary:** declare `SOCKET_MARKER = "redis.socket"` and `PIDFILE_MARKER = "redis.pid"` beside `EPHEMERAL_PREFIXES`; use them in new/changed code; add a parity test that discovery finds either marker. Unification of the remaining pre-existing literal sites is **filed as a follow-up**.
7. **`tests/test_reaper.py:269` re-argument:** renamed; asserts **both** effects — absent under scoped `discover()` and present + `protected` under `discover(full_scan=True)`.
8. **`_AUTOGEN_DIRNAME` vs `EPHEMERAL_PREFIXES`** (`keep separate`, recorded): a one-line comment states why they differ (the former is a strict name-shape allowlist that can match dirs **outside** the tempdir, which the containment check cannot reach).
9. **The scheduled sweep stays scoped; `--full-scan` is operator-only.** Out-of-namespace dirs are **never actionable** (scope-equality proof), so rendering `--full-scan` into the 10-minute launchd/cron command would buy only a log line at ~1.0–1.3 s per run on the lane this issue is trying to lighten. The hatch is for `python -m tortoise.embedded_reaper --full-scan` and `tools/embedded_orphans.py --deep`.
10. **The issue's "Ask" is answered in-plan:** the global walk is load-bearing as a **mechanism** (a dead server has no cmdline, so pass 1 cannot replace it) and redundant only as a **scope**; `--full-scan` restores unscoped detection without restoring the cost.

## Outcome notes (post code-review)

The implementation differs from this plan where the code-review gate found the plan's claims wrong. The deltas, and why:

- **`_find_socket_dirs` was DELETED.** It had zero production callers (`tools/embedded_orphans.py` was migrated to `_scan_socket_dirs` in this same change) and it dropped `.complete`, re-opening the "partial set presented as a finished scan" class. The tests now call `_scan_socket_dirs(...).dirs`.
- **"detect-only" was WRONG for the kill verb.** `reap()`'s `_kill` has no ephemerality gate — only the *post-kill cleanup* does — and `_classify` admits a live out-of-namespace dir as `candidate`. `--full-scan` therefore **restores the pre-#4068 un-scoped enumeration** (it can reach nothing an earlier release could not), and scoped discovery's kill-losslessness rests on the **pass-1 lemma** (live servers are enumerated name-independently), now stated at the claim site and pinned by `test_live_candidate_is_found_by_pass1_regardless_of_dir_name`.
- **Completeness is read FAIL-CLOSED.** `_run_sweep` wraps the discovery result with `_as_scan_aware` (an unknown/plain-list result reads as incomplete), and `_sweep_quarantine_dirs` now returns a `_ScanAwareList` so a truncated **quarantine** scan is ANDed into the sweep summary instead of being hidden behind pass 2's flag.
- **`_scan_socket_dirs`'s `deadline=None` means "default budget", not unbounded** — #1642 FIX 2 made the walk always time-bounded, and a direct caller must not silently lose that backstop.
- **The ordering test was rewritten.** `DirEntry.is_symlink()` is C-level and invisible to an `os.stat` counter, so that test could not observe the ordering it claimed to pin; it now counts predicate vs `is_symlink()` invocations directly.
- **Two adversarial tests were rewritten** (`test_symlinked_decoy_dir_never_reaped`, `test_namespace_match_with_escaping_realpath_refused`): with a plain file, both aborted at the socket-probe guard and proved nothing about containment. They now use a real dead unix socket (bind+close) and assert the escape/refusal precondition.
- **`_ScanAwareList` (a `list` subclass) is kept deliberately** — `discover()`'s return type is read as a list at ~25 call sites, so a result object (the `tortoise/index_walk.py::WalkResult` shape) is a follow-up, not this fix. It is documented, and every reader reads it fail-closed.
- **`OVERRIDES:`** is carried in the code comment beside `SOCKET_WALK_TIMEOUT` and on issue #4068.

```python
SOCKET_MARKER = "redis.socket"
PIDFILE_MARKER = "redis.pid"

class _ScanResult(NamedTuple):
    dirs: list[str]
    complete: bool

class _ScanAwareList(list):
    """list subclass carrying a `complete` diagnostic (never part of the record schema).

    Defaults to complete=False (fail-closed): a construction path that
    forgets to set it must not read as a finished scan.
    """
    complete: bool = False


def _iter_candidate_dirs(tmpdir, *, predicate, deadline=None) -> _ScanResult:
    """Depth-1 enumeration of tempdir entries whose NAME matches predicate.

    The NAME test runs FIRST, before `is_symlink()` and before any stat —
    the point of replacing the depth-2 `find` (#4068): a foreign entry
    costs one dirent read, never a metadata call. Only name-matching
    entries are then tested for symlink-ness; a symlinked entry is SKIPPED,
    preserving parity with `find` without -L (which does not descend a
    symlinked dir). `deadline` is an ABSOLUTE monotonic cutoff (the
    reap()/_run_sweep convention); it is sampled every iteration, so an
    already-expired budget always yields complete=False + WARNING — never
    a silent [].
    """
    dirs: list[str] = []
    complete = True
    try:
        with os.scandir(tmpdir) as it:
            for entry in it:
                if deadline is not None and time.monotonic() >= deadline:
                    complete = False
                    logger.warning(
                        "tempdir scan budget expired — returning partial "
                        "name-scoped set (%d dirs so far)", len(dirs))
                    break
                if not predicate(entry.name):
                    continue          # cheap dirent test — no stat
                if entry.is_symlink():
                    continue          # find -P parity
                dirs.append(entry.path)
    except OSError as exc:
        logger.warning("tempdir scan failed for %s: %s", tmpdir, exc)
        complete = False
    return _ScanResult(dirs, complete)


def _scan_socket_dirs(tmpdir, *, full_scan=False, deadline=None) -> _ScanResult:
    res = _iter_candidate_dirs(
        tmpdir,
        predicate=(lambda n: True) if full_scan
        else (lambda n: n.startswith(EPHEMERAL_PREFIXES)),
        deadline=deadline)
    out = []
    for d in res.dirs:
        try:
            if os.path.exists(os.path.join(d, SOCKET_MARKER)) or \
                    os.path.exists(os.path.join(d, PIDFILE_MARKER)):
                out.append(d)
        except OSError:
            continue
    return _ScanResult(sorted(out), res.complete)


def _find_socket_dirs(tmpdir, *, full_scan=False, deadline=None) -> list[str]:
    return _scan_socket_dirs(tmpdir, full_scan=full_scan, deadline=deadline).dirs
```
