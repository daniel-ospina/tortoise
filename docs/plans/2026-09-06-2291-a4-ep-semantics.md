## 0. Problem this plan solves

The A4 treatment arm today (battery/arms/a4_tortoise.py, 172 lines) is a **raw-Cypher mimicry** of the product, not a consumer of it: `setup_scenarios` → `batch_setup(proj, ..., namespaced=True)` drives raw `MERGE` through `FalkorProjection`; `retrieve` runs a bespoke `g.query("MATCH ... LIMIT 20")` with `confidence=None` always; `record` hand-writes `MERGE` point + operator + edge statements with a fresh `LIMIT 5` target pick and a `weight=0.3` mitigation that the engine never reads (annotation-only, #2315). Every R1–R5 metric that touches A4 therefore measures a mock — the differential compares product vs nothing. #2291 swaps the verb channel to the REAL SDK surfaces (sdk.ingest for seeds with batch_id provenance; create_point/create_operator/mitigate/supersede for agent writes with targets from the retrieved closed set; recall_state/tortoise_fts_query/compute_confidence/recall_subgraph for reads) over the SAME #2284 Task-4 `seed_mode` content contract, makes ep_outcome honest (terminal table, never hardcoded), and makes loopy graphs constructible so R3 honest-UNDEC is reachable. Every genuine product gap found is FILED (never absorbed into the harness) — #2315 is the model.

**Falsification (any ⇒ unsolved):**
1. Raw Cypher remains in the real-run A4 write OR read path.
2. A bespoke (non-product) read surface feeds probe-consumed fields on the real path.
3. Seeds land without product-real EP state; the ARM ever passes `require_calibration=False` (product-internal capture-refresh calls are exempt — the ban binds the harness, not the product's own seams).
4. ep_outcome can read CONVERGED without a real engine `converged=True` + non-empty affected set.
5. lp-* loopy graph not constructible → honest-UNDEC unreachable.
6. No lane-matrix doc + enforcement (one access mode per lane).
7. Draft seeds/agent-writes make EP reads vacuous (#780) with no explicit promote step.
8. [cal] ep-variance row absent from thresholds.yaml (mechanism-liveness leg unbuildable).

## 1. Design invariants (binding)

- **One SDK per scenario, same handle for write and read.** `TortoiseSDK(db_path=<per-run tmp embedded store>, graph_name=battery_<scenario_id>, event_log_path=<per-run tmp>)` created at setup per scenario; retrieve/record resolve the scenario's handle. Redirect-immune: explicit `db_path` ignores `TORTOISE_DB_URI`; per-run tmp store is never `tortoise_test_matrix`; env stripped of `TORTOISE_DB_URI`/`TORTOISE_DB_PATH` in the fixture.
- **The reference lane stays, read-only.** #2284 Task-4's hermetic batch raw-MERGE path (`battery/runner/setup.py` + `battery/testing/seeds.py`) remains for (a) the carve-out equivalence tests and (b) content-absence enforcement — NEVER on the real A4 path. Audit allowlists it by name only.
- **seed_mode content contract (Task 4 of #2284) preserved on the ingest channel:** contradiction scenarios seed claim_a + evidence ONLY; ¬A (claim_b / k-turn statement) NEVER pre-seeded — arrives in-context at turn k at run time; warm-store guard via a seeder-owned `seed_manifest` marker refuses a stale PRE-FIX graph in the same namespace (fail-closed BEFORE `batch_id` is minted), while a clean seed_mode graph re-setup accumulates (Task-10 stream default).
- **Seed calibration = promote-then-EP-compute (primary).** `sdk.ingest(bundle, granularity="bulk", promotion_policy="gated")` → `promote_point` on seed POINTS (operators ride; `promote_point` blocks operators) → product EP compute via `compute_confidence(factors=..., evidence=...)` over the seeded subgraph. Never `require_calibration=False`. Verify-at-scope ordering (Task 2): prove the route satisfies `compute_confidence`'s fail-closed `TORTOISE_EP_REQUIRE_CALIBRATION` gate on the embedded lane BEFORE any auto-calibration reliance; failure → FILE (never flag-flip, never re-baseline the gap as expectation).
- **#901 routing, engine-honored:** truth → NAND the finding (`create_operator("NAND", source, [target], direction="unidirectional")`); relevance → mitigate the OPERATOR (`mitigate_operator(id, reason, strength)`, clamp [0.10, 0.50], idempotent); supersede for replacement (`supersede_point`); `promote_source=True` on the arm's own edges (live sources — #780). Mitigation EP-effect is NOT asserted on claim-EP deltas (pre-registered; annotation-only per #2315).
- **Empty retrieved closed set ⇒ zero writes + honest no-op recorded** (locked regression: `claims[0]` dead by construction can never produce a write).
- **ep_outcome terminal table (honest, decisive-only consumers):** `converged` (engine `converged=True` + within-[cal]-variance decisive + non-empty affected set written back) | `non_converged` (engine `converged=False` after decide cap) | `undec` (loopy non-convergence in cap OR engine diagnostic) | `contested` (variance > [cal] ep-variance row — NON-DECISIVE BY CONSTRUCTION even when `converged=True`; numeric converged+variance retained — mechanism convergence ≠ decisiveness) | `no-op` | `excluded`. R3 ground truth = the non-decisive set {undec, contested} is never CONVERGED; consumers (Task-8 liveness, verify-at-scope, R3 scorer) read DECISIVE within-row outcomes only; verify-at-scope never validates [cal] rows against contested records.
- **Decide cap:** `decide_cycles` arm-side per-episode counter, default cap 8; cap-hit ⇒ `non_converged`/`undec`, never forced CONVERGED.
- **thresholds.yaml [cal] ep-variance row** re-locked in this issue and passed EXPLICITLY as `variance_threshold` to the variance read — `tortoise/` defaults (0.04) untouched. Row read-only to #2284 Tasks 7/8 (they consume, never write).
- **Lane matrix documented + enforced** (Task 1): one access mode per lane; tests assert zero raw `proj.g.query` on the real path (allowlist = reference lane only); docker lane optional + code-identical (store-mode-only delta allowlist + lane-invariant assertion list).
- **ONTOLOGY unchanged.** Additive point props only (`seed: true`, `batch_id`, provenance tags, `ep_outcome`/`decide_cycles` in the log/read-out, never schema fields).
- **#2293 alignment:** event ordering owned by #2293; this arm's `event_log_path` is a correlation channel (per-run tmp), never a second write channel; event_ref ns:seq captured ns = graph_name.

### Task 3 (RED→GREEN): Write channel via SDK verbs, closed-set targets (I-3)

**Intent:** The agent's writes become product verbs with targets derived ONLY from the retrieved closed set — no fresh store probe at write time, no operator fabrication, no engine-silent weights.

**Acceptance:**
- `record(context, item)` on the real path: evidence point via the product create surface; NAND/mitigate/supersede routed per #901 semantics with target ids taken from `context.prior_memories` (the retrieved closed set) — item.target if present must be a member of the closed set else the write is refused (honest no-op + reason recorded).
- Empty closed set ⇒ zero writes + honest no-op recorded (locked regression named `empty_set_never_writes`).
- `item.kind == "nand"` → `create_operator("NAND", evidence_source_id, [target_id], direction="unidirectional", promote_source=True)`; `item.kind == "mitigate"` → `mitigate_operator(operator_id, reason=item.content, strength=clamp(item.weight, 0.10, 0.50))` — operator_id from the closed set (the operator the agent is mitigating), never a fresh LIMIT pick; supersede path for replacement writes via `supersede_point`.
- Idempotency: re-recording the same evidence content does not duplicate points/operators (content-hash semantics preserved).
- `decide_cycles` increments per record; cap default 8; cap-hit → the arm reports non-converged state, never forces CONVERGED.
- Mid-run failure policy: `CalibrationError`/`ArmUnavailable` on a write/read ⇒ raise `ArmUnavailable` → runner marks the episode EXCLUDED with reason; the arm NEVER swallows and fabricates from an uncalibrated store; excluded episodes counted + reasons reported (consumes #2284 Task-5 emitter seam when real).
- `promote_source=True` on arm-created edges so agent evidence goes live (#780: compute_confidence excludes draft) — locked test that a draft-only agent write is NOT confidence-visible until promoted, mirroring the product semantic.
