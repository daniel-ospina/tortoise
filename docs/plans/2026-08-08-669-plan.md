## Data Model (migrations 0006–0009 — 0005 exists, no collision)
- **0006 `teams`** — id (text PK; ULID or 26-hex — no hex-only CHECK), name, tier, created_at, stripe_customer_id, subscription_id, backup_enabled, backup_latest_at, backup_restored_at, max_users/teams/graphs, ops_allowance, graph_size_cap, **graph_name (required — sdk.team_create uses team_{name}, not team_{id})**, email, onboarding_state (jsonb), github_token_enc (column-REVOKEd), github_org. RLS: GUC `current_setting('app.current_team_id')` (audit-0002 precedent) + service-role writes.
- **0007 `api_keys`** — id, team_id FK, lookup_hash (unique index), key_prefix, created_via ('provisioned'|'bootstrap'|'recovery', **NOT NULL default 'provisioned'**; reconcile rewrite defines the new unrevealed predicate e.g. revealed_at IS NULL), created_by (nullable), last_used_at, expires_at, revoked_at, created_at. **REVOCATION SOURCE OF TRUTH (P1-2): api_keys.revoked_at; apikey_verify resolves hash across team_memberships + api_keys and rejects if the api_keys twin is revoked.**
- **0008 `invitations`** — id, team_id FK, lookup_hash (SHA-256, **indexed** + partial unique on pending), role, invited_by, email, status, accepted_at, expires_at; partial unique (team_id, email) on pending.
- **0009 extend `team_memberships`** — add lookup_hash (indexed); **DROP chk_member_or_invite, replace with `user_id IS NOT NULL OR invited_email IS NOT NULL OR identity IS NOT NULL`; user_id FK stays but NULLABLE (agent-signup P1-3)**; add identity (nullable).
- **Lookup scheme (P1-1):** `lookup_hash := SHA-256(pepper + key)` — one shared Python helper + mirrored TS function + TS↔Python test-vector parity test. Keep the salted `key_hash` column (continuity) or drop explicitly. Legacy salted hashes are un-migratable without plaintext → **the flip gate requires zero non-placeholder rows in BOTH stores** (registry AND team_memberships/api_keys), making legacy-hash migration a no-op.
- **Audit (P2):** ALTER `audit_events.actor_user_id` → TEXT (0002 is UUID; logger is TEXT; non-UUID actors would fail).
