# #1930 Implementation Plan — TORTOISE_PACKS_DIR env override + fail-safe resolution order

> **For Pi:** Implement task-by-task (TDD), then run `commit-workflow`.

**Goal:** Self-host operators configure a custom pack directory via `TORTOISE_PACKS_DIR`
with a fail-safe resolution chain (env → packaged default → repo root) that warns —
never silently degrades to an empty registry — on every fallback trigger.

**Team:** epistemic-team
**Epic:** #1891 (05-plan.md §2 WF-2, §6 Env; test-design #1898 surface 3)

**Architecture:** The env leg lives in the #1929 single resolution primitive
(`pack_registry.default_packs_dir()`), so ALL seven consumers (domain_loader,
extractor_v2, value_extractor, sdk, commit_schema, query_suggestions) honor the
override with one resolution rule. A new `env_packs_dir()` helper resolves the
env leg with warn-once fallback (missing / not-a-dir / zero loadable manifests).
`load_all()` gains warn-not-silent for isolated packs (one change → every
consumer warns, E2E-2's startup warning). `domain_loader._get_registry()` closes
the all-manifests-broken gap AND the load-raises gap: warn + sticky fallback to
the skip-env default, so the daemon registry (`tortoise_packs_list`'s catalog
join) is never silently empty. `TORTOISE_STARTER_PACKS` warn-skip is untouched
(preserved = regression test only).

**Documented asymmetry (verifier-adjudicated):** the all-broken/load-raises
*fallback* applies to the daemon registry (`_get_registry()`); the six direct
consumers (sdk/extractor_v2/commit_schema/query_suggestions/value_extractor)
resolve the env dir and get the Task-2 load warning + their existing ponytails
(base vocabulary, no crash). Per-process consumer caches (sdk `_get_kind_expander`,
extractor_v2 forms) are process-lifetime — the issue's "after restart" semantics
are satisfied by a fresh process re-resolving the env leg; a mid-process env
change is not honored by those caches (pre-existing, documented, not fixed here).

```python
_WARN_ONCE: set[tuple] = set()   # warn-once sentinel: (category, key...)

def _warn_packs_once(key: tuple, msg: str, *args) -> None:
    if key in _WARN_ONCE:
        return
    _WARN_ONCE.add(key)
    log.warning(msg, *args)

def env_packs_dir_value() -> str:
    """Raw stripped TORTOISE_PACKS_DIR value ('' when unset/blank)."""
    return os.environ.get("TORTOISE_PACKS_DIR", "").strip()

def _has_loadable_manifests(d: Path) -> bool:
    # Same namespace skip rules as PackRegistry.load_all (no _/. dirs).
    return any(
        m.is_file()
        for child in d.glob("*")
        if not child.name.startswith(("_", "."))
        for m in child.glob("manifest.yaml")
    )

def env_packs_dir() -> Path | None:
    """TORTOISE_PACKS_DIR env leg. None + no warn when unset/blank; set-but-
    missing/not-a-dir/zero loadable manifests → warn-once + None (caller falls
    back to default_packs_dir()); set+valid → the dir."""
    val = env_packs_dir_value()
    if not val:
        return None
    env_dir = Path(val).expanduser()
    if not env_dir.exists():
        _warn_packs_once(("env-dir", val, "missing"),
            "TORTOISE_PACKS_DIR=%r does not exist — falling back to the default pack catalog", val)
        return None
    if not env_dir.is_dir():
        _warn_packs_once(("env-dir", val, "not-a-dir"),
            "TORTOISE_PACKS_DIR=%r is not a directory — falling back to the default pack catalog", val)
        return None
    if not _has_loadable_manifests(env_dir):
        _warn_packs_once(("env-dir", val, "empty"),
            "TORTOISE_PACKS_DIR=%r contains no pack manifests — falling back to the default pack catalog", val)
        return None
    return env_dir
```

`default_packs_dir()` gains the env leg at the top and reuses the skip-rules
glob for the packaged leg (`_skip_env` is a PURE kwarg for the S1a/S1b
re-resolve — no env/global mutation; closes the pre-existing packaged-leg
`_template`-only hole, P4):

```python
def default_packs_dir(*, _skip_env: bool = False) -> Path:
    if not _skip_env:
        env_dir = env_packs_dir()
        if env_dir is not None:
            return env_dir
    packaged = Path(__file__).resolve().parent / "packs"
    if _has_loadable_manifests(packaged):
        return packaged
    repo_root = Path(__file__).resolve().parent.parent / "packs"
    if packaged.is_dir() and not repo_root.exists():
        _warn_packs_once(("packaged-stub", str(packaged), str(repo_root)),
            "packaged packs dir %s contains no manifests and repo-root "
            "fallback %s does not exist — registry will load 0 packs",
            packaged, repo_root)
    return repo_root
```

Update the `default_packs_dir()` docstring: env leg implemented (no longer
"adds the ... leg in front" — now "resolution order: TORTOISE_PACKS_DIR (env) →
packaged → repo root; _skip_env is the internal escape hatch for the
registry-level all-broken fallback").

```python
def _get_registry() -> PackRegistry | None:
    """Lazily load the pack registry once; None if packs are unavailable.

    The adapter must never break the legacy vocabulary — any load failure
    degrades to the base/registered kinds only (ponytail), and is LOGGED
    (never silent). TORTOISE_PACKS_DIR (env leg) is resolved through
    default_packs_dir(); when the env dir yields 0 valid packs or its load
    raises, warn + sticky-fall back to the packaged/repo default (S1a/S1b) so
    the daemon registry is never silently empty (G1 class, epic #1891 WF-2).
    """
    global _registry, _env_fallback_key
    from tortoise.pack_registry import (
        _warn_packs_once,
        default_packs_dir, env_packs_dir, env_packs_dir_value,
    )
    env_val = env_packs_dir_value()
    if _PACKS_DIR is not None:
        packs_dir = _PACKS_DIR
    elif _env_fallback_key is not None and _PACKS_DIR is None and env_val \
            and env_val == _env_fallback_key:
        # Sticky branch (S1a/S1b landed): skip the broken env dir. The
        # _PACKS_DIR guard mirrors the set-side guards — test injection must
        # always win over env, even after a fallback (cycle-2 P3).
        packs_dir = default_packs_dir(_skip_env=True)   # sticky: broken env dir
    else:
        packs_dir = default_packs_dir()
    if _registry is None or _registry.packs_dir != packs_dir:
        with _registry_lock:
            if _registry is None or _registry.packs_dir != packs_dir:
                try:
                    reg = PackRegistry(packs_dir)
                    reg.load_all()
                    if (not reg.packs and reg.errors and _PACKS_DIR is None
                            and env_val and env_packs_dir() == packs_dir):
                        # S1a: env leg active but every manifest failed
                        # validation — the empty-registry defect class (G1).
                        _env_fallback_key = env_val
                        packs_dir = default_packs_dir(_skip_env=True)
                        log.warning(
                            "TORTOISE_PACKS_DIR=%r: 0 valid packs (%d isolated) "
                            "— falling back to the default catalog %s",
                            env_val, len(reg.errors), packs_dir)
                        reg = PackRegistry(packs_dir)
                        reg.load_all()
                        reg.fallback_note = (
                            f"TORTOISE_PACKS_DIR={env_val}: 0 valid packs; "
                            f"loaded default catalog {packs_dir}")
                    _registry = reg
                except Exception as e:  # noqa: BLE001, RUF100 — ponytail
                    if (_PACKS_DIR is None and env_val
                            and env_packs_dir() == packs_dir):
                        # S1b: the env-dir load itself raised — fall back once.
                        _env_fallback_key = env_val
                        packs_dir = default_packs_dir(_skip_env=True)
                        log.warning(
                            "TORTOISE_PACKS_DIR=%r: pack load failed (%s) — "
                            "falling back to the default catalog %s",
                            env_val, e, packs_dir)
                        try:
                            reg = PackRegistry(packs_dir)
                            reg.load_all()
                            reg.fallback_note = (
                                f"TORTOISE_PACKS_DIR={env_val}: load failed; "
                                f"loaded default catalog {packs_dir}")
                            _registry = reg
                        except Exception as e2:  # noqa: BLE001
                            _warn_packs_once(("ponytail", "default-load"),
                                "pack registry load failed, degrading to "
                                "legacy vocabulary: %s", e2)
                            _registry = None
                    else:
                        _warn_packs_once(("ponytail", str(packs_dir)),
                            "pack registry load failed, degrading to legacy "
                            "vocabulary: %s", e)
                        _registry = None
    return _registry
```
