# #1546 — A1 Partial-Knowledge Abstention Clause — Implementation Plan

> **For Pi:** Use `executing-plans` to implement this plan task-by-task.

**Goal:** Make the reader abstain from evidence (state what IS present; explicitly state the asked info is absent) instead of committing to a near-miss decoy — with the `_abs` flag never crossing into the reader path.

**Team:** epistemic-team

**Architecture:** One new always-on prompt fragment (`_ABSTRACTION_FRAGMENT`) appended by `system_prompt_for()` in `tools/longmem_eval/reader.py` — no signature change, no new data, no new fields. The clause is **universal** (applied to every question type) because abstention questions are indistinguishable by `question_type`: the `_abs` marker lives only in `question_id`, which the reader call site must never receive (E2E-7 invariant). Behavior is proven red→green with a prompt-faithful test double + MockJudge; the call-site invariant is locked by a guard test.

## Design Decisions

### D1 — Universal clause, not type-keyed (the core of "never the `_abs` flag")
The dataset marks abstention via a `_abs` suffix on `question_id` only — `question_type` is the ordinary type (e.g. `single-session-user`; the committed mini fixture's `mini_abs_005_abs` is `question_type="single-session-user"`). The reader receives `question_type` only (run.py:192–197 already satisfies this). Therefore the abstention guidance **cannot** be keyed on anything type-level: it must be an always-on clause that lets the reader *derive* unanswerability from the evidence (hits, dates, supersession markers, absence of the exact fact). Any attempt to pass a flag or the qid is a violation of E2E-7 and is explicitly forbidden (see ⛔ Conditional gates).

### D2 — New `_ABSTRACTION_FRAGMENT` constant, appended before the type fragment
Mirrors the existing `_TEMPORAL_FRAGMENT` / `_PREFERENCE_FRAGMENT` pattern: a named module-level constant. `system_prompt_for` composes `_SYSTEM_PROMPT + _ABSTRACTION_FRAGMENT + _TYPE_FRAGMENTS.get(question_type, "")` in both branches. Order choice: the type fragment (temporal/preference) lands **after** the abstraction clause, so its stronger commit-instructions ("Commit to a specific numeric answer — do not hedge") remain the final instruction for evidence-present cases — consistent with A1's own commit-side guard.

### D3 — Commit-side guard (no regression on #1366)
The clause licenses abstention **only** when the exact asked fact is absent, and explicitly forbids abstention when it is present. This preserves the #1366 fix (reader hedges/miscounts on evidence-present questions) — A1 widens the *abstention* path, never the *hedge* path.

### D4 — Evidence-backed phrasing (epic UX decision 1, verbatim contract)
"State what IS present; explicitly state the asked info is absent" — plus an example sentence containing the MockJudge marker phrase `does not contain` so the offline judge can score abstention without widening `MockJudge._ABSTRACTION_MARKERS` (keeps judge.py untouched).

### D5 — Explicit override of "do not mention the context"
`_SYSTEM_PROMPT` ends with "Be concise; do not mention the context." The official abstention template *requires* mentioning what is given. The clause overrides this for abstention answers only ("When you must abstain, you are expected to mention the related facts found in the memory — this overrides the 'do not mention the context' instruction").

### D6 — Empty-context (complete absence) case
The clause also covers "no related information at all → state the asked information is absent" — keeps the N/A-not-0.0 honesty (M6) at the answer level.

### D7 — Never-crosses assertion is scoped to prompt text + call shape
Under deterministic ingest, point `session_id` equals the qid, so a raw-hit dump of an `_abs` question contains the string `_abs` (provenance metadata, never rendered). The E2E-7 contract is "the reader is not *told* it's an abstention question": assert (a) the kwarg key set is exactly `{context_hits, question, question_date, question_type}`, (b) `question_type` is the raw dataset type (never "abstention"/None-for-abs), (c) the rendered context text (what the model actually sees) contains no `_abs`, (d) no fragment/prompt constant contains `_abs`. Raw hit `session_id` is documented as not-a-flag and excluded from the assertion.

### D8 — No judge.py / report.py change
`is_abstention(qid)` and the official unanswerable template stay exactly as-is (benchmark comparability). The `_abs` usage in `judge.py`/`report.py` is the judge/report surface — deliberately the *other* side of the E2E-7 boundary.

### D9 — Composition with existing temporal abstention license
The temporal fragment already has a narrow abstention license ("if the context contains NO dated evidence … say you do not know"). A1 generalizes it; no text is removed (the temporal license is type-specific and still correct).

```python
# ── 6. A1: partial-knowledge abstention clause (#1546) ────────────────────

_ABS_QUESTION = {
    "question_id": "pt_abs_001_abs",
    "question_type": "single-session-user",
    "question": "What is Ava's favorite color?",
    "answer": "The user never mentioned a favorite color in the provided history.",
    "question_date": "2025-06-15",
    "haystack_session_ids": ["sess-1"],
    "haystack_dates": ["2025-06-10"],
    "answer_session_ids": [],
    "haystack_sessions": [[
        {"role": "user", "content": "I really like my new bicycle.",
         "has_answer": False},
        {"role": "assistant", "content": "Tell me more about it."},
    ]],
}

ALL_TYPES = ("single-session-user", "single-session-assistant",
             "single-session-preference", "multi-session",
             "temporal-reasoning", "knowledge-update")


def test_abstention_clause_present_for_all_question_types():
    """A1 is universal — abstention questions are indistinguishable by type
    (the _abs marker lives only in question_id, which never reaches the
    reader), so every question must carry the clause."""
    for t in (None,) + ALL_TYPES:
        sys_prompt = system_prompt_for(t)
        assert "PARTIAL-KNOWLEDGE ABSTENTION" in sys_prompt, t
        assert "explicitly state" in sys_prompt.lower(), t
        assert "IS present" in sys_prompt, t


def test_abstention_clause_keeps_commit_side_guard():
    """A1 must not re-license the #1366 hedge: when the exact fact IS
    present the reader must answer directly, never abstain."""
    clause = _ABSTRACTION_FRAGMENT
    assert "do NOT abstain" in clause
    assert "exact information" in clause


def test_abstention_clause_never_keyed_on_abs():
    """No prompt/fragment text references the _abs convention — the clause
    is evidence-derived by construction."""
    all_text = _SYSTEM_PROMPT + _ABSTRACTION_FRAGMENT + \
        "".join(_TYPE_FRAGMENTS.values())
    assert "_abs" not in all_text
    # an abstention question gets the identical universal section as its
    # non-abstention twin of the same type
    assert system_prompt_for("single-session-user") == \
        _SYSTEM_PROMPT + _ABSTRACTION_FRAGMENT


class _EvidenceBackedAbstainingModel:
    """Proves the clause is what unlocks the behavior: WITHOUT the A1 marker
    in the system prompt this fake commits to the decoy (the pre-A1 failure
    mode — MockJudge scores it wrong); WITH it, it states the related fact
    AND the absence (evidence-backed abstention — MockJudge scores it
    right)."""

    _TURN = re.compile(r"\[user\] (.*?)(?:\[assistant\]|\[session|$)", re.S)

    def complete(self, *, system: str, user: str) -> str:
        m = self._TURN.search(user)
        decoy = m.group(1).strip() if m else "some related information"
        if "PARTIAL-KNOWLEDGE ABSTENTION" in system:
            return (f"The memory mentions {decoy}, but it does not contain "
                    "the asked information.")
        return decoy  # pre-A1: commits to the near-miss decoy


def test_clean_abstention_evidence_backed_end_to_end(tmp_path):
    """A1: the reader abstains cleanly on an absent fact — stating what IS
    present and that the asked info is absent — judged correct by MockJudge
    (existing marker: 'does not contain')."""
    reader = LLMReader(_EvidenceBackedAbstainingModel(), model_id="a1-faithful")
    outcomes, _ = run_evaluation(
        [_ABS_QUESTION], reader=reader, judge=MockJudge(), ks=(5,),
        top_k=20, split="s", work_dir=str(tmp_path),
    )
    assert outcomes[0]["label"] is True
    hyp = outcomes[0]["hypothesis"]
    assert "bicycle" in hyp            # states what IS present
    assert "does not contain" in hyp   # … and that the asked info is absent


def test_decoy_commit_negative(tmp_path):
    """Owned negative (E2E-7): related-but-not-target fact in context must
    NOT be committed to. Without the clause the fake commits the decoy and
    MockJudge returns False; with the clause it abstains evidence-backed."""
    class _PreA1Model(_EvidenceBackedAbstainingModel):
        def complete(self, *, system, user):
            # strip the A1 marker so the fake takes the pre-A1 branch
            return super().complete(
                system=system.replace("PARTIAL-KNOWLEDGE ABSTENTION", "X"),
                user=user)
    pre = run_evaluation(
        [_ABS_QUESTION], reader=LLMReader(_PreA1Model(), model_id="pre-a1"),
        judge=MockJudge(), ks=(5,), top_k=20, split="s",
        work_dir=str(tmp_path))
    assert pre[0][0]["label"] is False          # red: decoy commit is wrong
    post = run_evaluation(
        [_ABS_QUESTION], reader=LLMReader(_EvidenceBackedAbstainingModel(),
                                          model_id="a1-faithful"),
        judge=MockJudge(), ks=(5,), top_k=20, split="s",
        work_dir=str(tmp_path))
    assert post[0][0]["label"] is True          # green: clause present


def test_abs_never_crosses_reader_call_site(tmp_path):
    """E2E-7: the reader call site receives question_type only — no
    abstention kwarg, no question_id, and the reader-visible context text
    never contains the _abs marker. (Raw hit session_id provenance may
    carry the qid under deterministic ingest — that is metadata, not a
    flag, and is not rendered; the assertion targets prompt text + shape.)"""
    reader = _RecordingReader()
    run_evaluation([_ABS_QUESTION], reader=reader, judge=MockJudge(),
                   ks=(5,), top_k=20, split="s", work_dir=str(tmp_path))
    call = reader.calls[0]
    assert set(call) == {"context_hits", "question", "question_date",
                         "question_type"}
    assert "abstention" not in call and "question_id" not in call
    assert call["question_type"] == "single-session-user"  # raw type, never
    # "abstention"/None-for-abs
    text = render_context(call["context_hits"],
                          question_date=call["question_date"])
    assert "_abs" not in text and "pt_abs_001_abs" not in text
```

```python
_ABSTRACTION_FRAGMENT = (
    "\n\nPARTIAL-KNOWLEDGE ABSTENTION: the context can contain related "
    "information that does NOT actually answer the question. First check "
    "whether the context contains the EXACT information the question asks "
    "for. If it does, answer directly and concretely — do NOT abstain, and "
    "do not let unrelated material weaken your answer. If the exact "
    "information is absent, do NOT guess, do NOT infer, and do NOT commit "
    "to the closest matching fact. Instead, state what related information "
    "IS present (briefly), then explicitly state that the asked information "
    "is absent. When you must abstain, you are expected to mention the "
    "related facts found in the memory — this overrides the 'do not mention "
    "the context' instruction for abstention answers. If the context "
    "contains nothing related, simply state that the asked information is "
    "absent. Example: 'The memory mentions <related fact>, but it does not "
    "contain the asked information.'"
)
```

And update `system_prompt_for` (both branches):

```python
def system_prompt_for(question_type: str | None) -> str:
    """The reader system prompt for a question, type-tailored.

    Unknown/absent types get the hardened generic prompt; temporal-reasoning
    and single-session-preference append their reasoning instructions (the
    weak categories from issue #1366). A1 (#1546): the partial-knowledge
    abstention clause is appended UNIVERSALLY — abstention questions are
    indistinguishable by question_type (the _abs marker lives only in the
    question_id, which never reaches the reader), so the reader must derive
    unanswerability from the evidence, never from a flag.
    """
    return (_SYSTEM_PROMPT + _ABSTRACTION_FRAGMENT
            + _TYPE_FRAGMENTS.get(question_type, ""))
```

## ⛔ CONDITIONAL GATES

- **No ontology change.** No new kinds, edge types, properties, or expansion packs. A1 is prompt text + tests only (ontology invariant, owner-approved).
- **No new reader interface surface.** `Reader.answer` / `system_prompt_for` signatures are UNCHANGED — no `abstention=` kwarg, no `question_id` passthrough, no `_abs`-derived signal of any kind. Adding one would violate E2E-7's "the reader call site receives `question_type` only" and must be rejected in review.
- **No new point/hit fields.** The clause consumes the existing rendered context (hits, session dates, supersession markers).
- **No new dependencies.** Zero third-party libs — writing-plans Perplexity gate skipped (Micro tier + zero-deps rule).
- **Conditional (likely not needed): MockJudge marker extension.** Only if a review change moves the clause's exemplar phrasing off the existing markers (`does not contain` / `no information`) may `MockJudge._ABSTRACTION_MARKERS` gain a marker (e.g. `"is absent"`) — judge-side, eval-instrumentation only, never ontology. Default: avoid by keeping the exemplar phrase.
- **Conditional: M5 pin module.** If M5's pinning materializes as a distinct pinned-constants module (e.g. a `PROMPTS` dict), A1 must update the pin in the same change; if M5 has not landed when A1 starts, sequence A1 after it (issue's MECE note) — do not ship the clause outside the pinned prompt.

## Open Questions

1. **Clause position** — A1 before the type fragment (chosen: the temporal/preference commit-instructions land last, preserving their primacy on evidence-present questions). Flagged for plan-review; trivially reversible (one-line order swap).
2. **Never-crosses assertion strictness** — scoped to prompt text + kwarg shape, excluding raw hit `session_id` provenance (which carries the qid under deterministic ingest). If reviewers prefer a stricter "no `_abs` substring in any reader-bound data", the alternative is scrubbing `session_id` from annotated hits — a larger, separate change; default is the documented scope.
3. **Empty-context branch** — clause states "nothing related present → state the asked information is absent". Confirm at review this matches the owner's N/A-not-0.0 intent (M6) for zero-evidence questions.
4. **MockReader abstention behavior** — the offline mock returns evidence turns, so `mini_abs_005_abs` stays judged False (no evidence, no abstention markers). Intentional (mock is a retrieval wiring probe, not an abstention-capable reader); A1 behavior is asserted via the prompt-faithful fake. Confirm no expectation that MockReader abstains.
5. **"commit" wording** — the clause contains "do NOT commit to the closest matching fact"; verified harmless to `test_temporal_prompt_preserves_abstention_license` (asserts "commit" via the temporal fragment's own text; the fake model does not key on it).
