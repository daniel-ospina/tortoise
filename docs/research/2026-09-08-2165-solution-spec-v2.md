## Architecture (locked, v1)
**Pre-Routed Connected Assembly (PRCA).** A private pre-retrieval shape classifier (current-state / ordering / interval / date-lookup) fires a pool-REPLACING branch in `sdk.ask()`; the assembled block materializes as ordinary annotated hit dicts flowing through the UNCHANGED `assemble_context`/`render_context`/byte-caps machinery (whole-hit 8k-token/32-KiB caps, alignment invariant, D8 `[SUPERSEDED BY]`/`[SUPERSES]`/`[valid …]` markers, undated `[session ?]`); pure `tortoise/assembly.py` core (injected projection, function-level imports only) + shared `_assemble_connected()` consumed by BOTH `ask()`'s branch and the public `sdk.ask_assembled()` surface (recall_state/recall_subgraph precedent sdk.py:13327/13794). Zero new reader fragments, zero qtype-enum change, zero wire-field change. Env `TORTOISE_ASK_CONNECTED_ASSEMBLY` default OFF (register in `.env.example`; read via `ask_env_bool`; the eval arm keys off the SAME master flag). ask() branch precedes retrieval; `detect_question_type` NOT moved (stays post-retrieval, question-text-only → response `question_type` unchanged).

**Seam stance (resolves converge A-vs-B split):** `sdk.ask_assembled()` public method in v1, single-source `_assemble_connected()` shared with `ask()`'s branch; eval consumes `ask_assembled()`; NOT routed through `_post_ask` in hosted-delegated client mode (local-lane only, documented); NOT a metered surface; answer-surface.md surface-table note added. Agent A's converge summary committed for auditability (same decision, differing seam stance reconciled here).

## Verify findings → binding requirements (controller-accepted)

**R1 (P1-1) — Both-halves fire gate.** Router returns shape + required-subject count. Ordering/compare/interval fire ONLY when EVERY required subject resolves to ≥1 confident candidate. ANY required subject unresolved → fired=False → legacy byte-identical (legacy pool may still surface the missing half's point hits). One-half fire (single-subject block masquerading as a complete compare) is FORBIDDEN. Test: compare question with only one resolvable subject → fired=False, evidence byte-identical to legacy.

**R2 (P1-2) — Per-lane spine date contract.** Spine date precedence per row: (1) point `when` if present; (2) else point `createdAt`/session-date (the always-present v2-lane date); (3) else eventId-joined Event `startedAt` (product lane only — ingest_v2 points carry NO eventId, so the join is vacuous there BY DESIGN). The walker EMITS which tier dated each row (metadata, not reader-visible). Fixture mirrors ingest_v2 faithfully: no point-eventId, sparse `when` (extractor D3 semantics — stamp only state-change/decision/date-bearing), zero Event-aboutObject. The zero-eventId-join case is the PRIMARY fixture, not a variant. Undated rows render `[session ?]` last, no validity marker, never a fabricated/sentinel date (UNDATED_SENTINEL must never masquerade). Test: fixture point with neither `when` nor session-date renders undated-last.

**R3 (P1-3) — Eval arm has a baseline + conversion + matched control.** On the synthetic graph, same gold questions through (A) legacy pool evidence and (B) assembled-block evidence with the SAME pinned/stub reader; assert (B) ≥ (A) or pre-register report-only abstention-aware delta. ≥1 matched control (B-block vs B-block-order-shuffled OR B-block-plus-superseded-rows). Oracle tier (evidence-sessions-only) as upper bound where harness supports. The 13-Q reader-gain absence is recorded as an explicit follow-up decision, not an accident. Per-slice admission (metric a) AND reader conversion (metric b) both measured.
