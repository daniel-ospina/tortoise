### Bug Pattern Flags

- **Silent function skips (HIGH — the A0 risk):** onboarding flow could "complete" without the decide actually running (e.g. nudge fires, user dismisses, completion still set). Required: completion semantics regression test — `onboarding_complete` set ONLY on the fork's gate: **self = two Subjects + one decide + connected; build = org-anchor Subject + connected + catalog-presented-once (decide NOT required); compact = org-anchor Subject + harness-connected (seed-lite); dismissal alone never completes** (surfaces 8, 17).
- **Race conditions (MEDIUM):** W5 OnboardingState init must be transactional with org-create (surface 1, 3) — two concurrent agent init calls must produce exactly one node. Concurrent-install + concurrent-accept tests.
- **Conditional guards (MEDIUM):** fork card per-org-once guard; email-match three-case branching (surface 4, 12); mismatch-override OTP gate.
- **Privilege accumulation (HIGH, security):** account fusion yields UNION of memberships/permissions/api_keys (M10) — OTP proof-of-control is the required guard on mismatch-override (surface 12).
- **Contract drift (MEDIUM):** onboarding state registered-keys allowlist in hosted_api.py — new keys (fork, seed/decide checkpoints) must be registered or silently dropped (surface 1, 2, 4).
- **N+1 (LOW):** dashboard mirror reading per-checkpoint graph queries — batch the node read (surface 17).

### Checklist Notes

- **Atomicity:** org-create + OnboardingState init in one transaction (surface 3); new-user invite accept = atomic account+membership (surface 12); capture delete = session + receipt cleanup (surface 11).
- **Idempotency:** OnboardingState writes (#398 MERGE, never-overwrite — surface 1); backfill re-run no-op (surface 2); W11 events deduped once per org (surface 14).
- **Boundary values:** fork render count 0/1/2 (per-org-once); invite email-match 3 cases; OTP wrong/expired; session delete non-existent id; catalog module count 0/1/many.
- **Test layer notes (repo reality):** docker lane (`TORTOISE_DB_URI='docker://:falkordb@localhost:6379/tortoise_test_matrix'`) for graph surfaces; hosted-e2e (tests/e2e/hosted, pytest-playwright) for dashboard surfaces; contract tests where an API shape must be pinned; manual/browser for 6-harness install + walk-through.
- **Failure modes needing explicit test cases:** two simultaneous org-creates (surface 3); two simultaneous invite-accepts same token (surface 12); delete session during capture (surface 11); fork re-ask after completion (surface 4).
