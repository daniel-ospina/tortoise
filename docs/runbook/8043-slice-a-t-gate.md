## 2. The run — three arms on the C2 shape

Pool: **139 hits** — 103 for the flooded fact (79 statement restatements +
13 flood points entangled with the content-less class + 3 own-source turns +
8 raw chunks), **24 content-less
operator hits** (#2978's class), 4 value-critical claims (two same-frame
different-value pairs: `300`/`400`, `12`/`60`), 8 unrelated facts. Window:
**40 items** (wave §1's window), token budget far above the cap so the ITEM
bound is what binds. `pre_2978` is a **reconstruction** — the shipped
`assemble_context` with the pre-#2978 predicate restored (`_has_claim_text`
forced True, which removes exactly the one `continue` #2978 added).

| Arm | admitted | content-less slots | slots for the ONE flooded fact | value claims in the window |
|---|---|---|---|---|
| `pre_2978` *(reconstructed)* | 40 | **24 (60.0%)** | **16 (40.0%)** | **0/4** |
| `post_2978` *(shipped predicate)* | 40 | 0 | **40 (100.0%)** | **0/4** |
| `post_2978_assembly` (**A6 arm ON**) | 14 | 0 | **2** (= 1 + `max_verbatim`) | **4/4** |
| `post_2978_assembly_value_marked` | 14 | 0 | 2 | 4/4 (value-mark census: 4 packages) |
| `provenance_free_assembly` (**#8658** — pre-fix product lane / today's degraded fallback) | 24 | 0 | **12** | 4/4 |

Controls — **two** of them, because one pool cannot exercise both clauses
(#9114):

* `no_dupe_no_regression` — a duplicate-free, provenance-bearing pool of 8
  **statement** facts comes back **byte-identical** from the arm (0 collapsed,
  same ids, same order). Byte-identity is the right assertion *here* precisely
  because every hit shares one hit-type tier.
* `no_dupe_tier_boundary` — the same duplicate-free pool with a raw **chunk**
  ranked **above** the statements. Under D3 (#9092) the chunk (tier 2) is
  demoted behind every statement (tier 0), so `ids_identical` is **false by
  design** and blanket byte-identity would assert the wrong clause. The two
  assertions this pool *can* falsify are `tier_regroup_matches_key` (the
  packaged order equals the stable `_package_type_tier` projection — it fails
  if the tier key leaves the sort) and `ids_identical_within_tier` (the
  regroup disturbs no tier peer). Both are **true** on the shipped code, and
  `test_tier_control_fails_when_the_tier_key_leaves_the_sort` executes the
  falsification. Hermetic pin of the same clause:
  `tests/test_evidence_assembly.py::test_unmarked_mixed_type_pool_regroups_by_hit_type`.

### What the numbers say

1. **The baseline expired, and it expired in a measurable direction.** The
   pre-#2978 predicate spends **60%** of the C2 window on hits that render
   nothing — the measured `61.3%` class of #2978. That composition cannot be
   reproduced today: the pipeline no longer admits those hits.
2. **#2978 did NOT bound the flood.** Removing the empty hits **reallocates**
   the freed slots to the highest-ranked *real* hits — and on a coverage-loop
   flood those are the duplicates: the shipped predicate alone gives **100%**
   of the window to **one fact**, and the value-critical claims get **no** slot.
   The #2683 defect is undiminished on this shape; it is a different defect from
   #2978's.
3. **The assembly is what bounds it** — one fact to `1 + max_verbatim` slots,
   with the freed slots going to distinct evidence, and **4/4** value-critical
   claims admitted. That is the product claim Slice A makes, measured.
4. **The bound is lane-scoped, and the instrument measures the limit rather
   than assuming it away.** Without `quote`/`source_turn_id`, pass 2 (a point's
   OWN source chunks/turns) is inert: 12 flood slots instead of 2. Pass 1's
   content legs are provenance-independent and still dedup the *statement*
   flood. That was the product ask lane's state until **#8658** landed; it
   remains the state of a **degraded fallback** read, whose projection carries
   no provenance.

> ⚠️ **The number this is NOT.** `2 vs 100%` is a *window composition* result,
> not a QA result. The old T wanted "the 2 C2 flooding regressions recover" — an
> **answer-accuracy** delta under a frozen reader. Nothing here substitutes for
> it, and no reader/judge number may be derived from this receipt.

### Instrument soundness — the receipt states only what it measures (#8945, #9114)

Two defects in the *instrument* (not in the product) were found after this
receipt was first cut, and both are repaired here. Neither moved a product
number; both moved what the receipt may be quoted for.

| Defect | What it was | Repair |
|---|---|---|
| **#8945** — a comparison nothing ran | The `value_safety` verdict's leading clause was built **unconditionally**: it printed *"pairs sit below the 0.90 collapse threshold"* for any input, including a run whose overlap was 0.99. And the one number it named (`overlap`) was the **quote** overlap, while 0.90 (`DEFAULT_PACKAGE_VERBATIM_OVERLAP`) governs **content** — two quantities under one label. | The receipt now emits `content_overlap` and `quote_overlap` **separately**, each beside its own threshold (0.90 near-verbatim / 0.75 same-turn), each with a **computed** `*_below_threshold` and `*_leg_reachable`. The sentence is composed from those fields by `_value_pairs_sentence`, so it cannot outrun them; `test_value_pairs_sentence_is_composed_not_fixed` feeds a forced-above pair and fails if the wording does not flip. The `hasattr(retrieval, "_pkg_overlap")` guard was also removed — it degraded a rename to a plausible `null`. |
| **#9114** — a control that could not fail | `controls.no_dupe_no_regression` was built from `_point` only, so every hit shared one D3 tier and `ids_identical` was **trivially true**: it measured "statement-only pools are untouched", never the tier boundary. | A second control, `no_dupe_tier_boundary`, ranks a raw **chunk above** the statements (0 duplicates). Under D3 that pool **is** regrouped, by design — so it asserts `tier_regroup_matches_key` (packaged order == the stable `_package_type_tier` projection) and `ids_identical_within_tier`, with `ids_identical` recorded as the **false-by-design** value it is. `test_tier_control_fails_when_the_tier_key_leaves_the_sort` removes the tier key from the sort and asserts the control reds. |

What the corrected figures showed on the existing fixture: the 300/400 pair's
**quote** overlap is **0.80 — above the 0.75 same-turn threshold**, a fact the
old single mis-labelled number concealed (it was reported as sitting below
0.90). The pair is still not a collapse candidate, because that leg also
requires a shared `source_turn_id` and the two hits sit on **distinct turns** —
so the conclusion is unchanged, but it is now reached from a checked
precondition rather than from a threshold the leg does not use.

| Leg | Statement | State |

**Why T-1 is the right re-specification and not a substitute dressed up as
one:** it measures the exact property the old T's second clause was protecting
("Slice A must make the product robust" to a flooding window) and it is the
part that never needed a reader. What it cannot do — and does not claim — is
produce an answer-quality number. That is T-2's job, kept separate on purpose.

### 4.3 Why the two arms were **NOT** retired

The issue offers withdrawal as the alternative ("the arms are OFF everywhere, so
nothing regresses on withdrawal") — and the arms **are** OFF everywhere
(re-measured §1). It was **not** taken, deliberately:

* withdrawing would reverse a delivered, evidence-backed, hermetically tested
  capability (`docs/scoping/2026-09-09-evidence-assembly-wave.md` §4; the
  hermetic suite in `tests/test_evidence_assembly.py` + the guard here)
  **on the grounds that a
  measurement was hard to run** — the easy path, not the good one;
* the measurement is not hard any more: `TORTOISE_LME_EVIDENCE_ASSEMBLY` is
  **read only at retrieval time** — one read site, `tools/longmem_eval/
  retrieve.py` (A6); the ask lane's product-side sibling
  `TORTOISE_ASK_EVIDENCE_ASSEMBLY` is likewise read only in `retrieve`-time
  code (A8, `tortoise/ask_lane.py`) — and none of the ingest cache's own inputs
  changes when either flips (`ingest_cache_fingerprint`: extractor code
  version, extraction model id, extraction prompt digest, the question id, the
  question JSON, `chunk_turns`, `session_workers` — no such flag among them;
  both are also absent from the read-side knob list the run fingerprint
  records), so flipping
  the LME flag **alone** does not invalidate the ingest cache. The ON/OFF A/B therefore costs **2× reader+judge calls and
  0 extra ingest** — the cheapest end-to-end arm available.
* withdrawing is trivially reversible later; re-deriving the capability is not.

### 4.4 Where T-2 is re-homed

**Owner of record: the end-to-end run in #8486** (*"Run the LongMemEval-S
end-to-end QA benchmark (PENDING — never executed; no comparable number
exists)"*, P1-severe). The relay is
posted on **#8486** itself (the artifact the lane that runs the benchmark
reads), stating the exact obligation:

* on the frozen 50 qids (a subset of the 500-Q corpus, so it rides the same
  run), run the reader/judge pass twice: `TORTOISE_LME_EVIDENCE_ASSEMBLY` OFF
  (the post-#2978 baseline) and ON (the arm);
* record the ON/OFF delta, the reader id and the judge id in the run report;
* if the judge is the labelled deterministic substitute, say so in the same
  record (wave §6: every product number carries its method line);
* **0 extra ingest** — the arm is not fingerprinted (§4.3).

Until that runs, `#2683`'s T is **owned, not silent** — which is #8043's target
2 ("declared acceptance gate has neither an owner nor a run").
