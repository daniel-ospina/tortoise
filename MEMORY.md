Raw things that bite mid-code. Not an implementation log, not a docs index.
Format: `[category]: [what broke] → [root cause] → [the fix]`. Cap: 150 lines.

[grep]: `git grep -E` is POSIX ERE and has **no** `\b`, so a census pattern carrying `\b(...)\b` matches NOTHING and prints a clean "no matches" — a false negative indistinguishable from the real answer it was asked for (a read-instrument census nearly reported "no instrument exists" for the wrong reason) → drop `\b` (the names are specific enough) or use `-P`, and print the grep's exit code beside every result so an empty answer is visibly an answer.
