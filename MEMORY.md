# MEMORY.md — coding gotchas

Raw things that bite mid-code. Not an implementation log, not a docs index.
Format: `[category]: [what broke] → [root cause] → [the fix]`. Cap: 150 lines.

[env]: `uv run python /tmp/probe.py` from a worktree imported `tortoise` from a **different worktree** → the shared `.venv` has an editable install, and `uv run` without `--no-sync` re-resolves it → always `PYTHONPATH=$PWD uv run --no-sync python ...`, and print `tortoise.__file__` to confirm before trusting any result.
[test]: A perf assertion on wall-clock time in a shared docker FalkorDB measured every *concurrently running* suite, not the code under test → flaky by construction → assert a **count** of operations instead (wrap `proj.g` in a proxy exposing `query()` and count Cypher round-trips), with a generous hang-backstop only as a safety net.
[test]: `FalkorProjection.from_uri(DB)` **bypasses** the test-graph URI redirect → under `TORTOISE_DB_URI` + `TORTOISE_TEST_MODE=1`, `FalkorProjection(explicit_path)` is redirected to a per-test graph `test_<stem>_<hash>`, but `from_uri` lands on the **shared** graph → construct via the explicit path in tests, never `from_uri`, or the test silently pollutes the shared graph.
[test]: `FalkorProjection._assert_test_graph` blocks bulk `DETACH DELETE` on a **server-mode (docker) graph** whose name does not start with `test_`/`tortoise_test` → the guard returns early for embedded mode (`path=`), which is inherently isolated, so it only protects shared server graphs → the guard is deliberate; rename the graph rather than working around it.
[process]: Writing a test file by **appending the plan's fenced code blocks verbatim** produced semicolon statement pairs (E702 ×40), `l` as a loop variable (E741 ×9), mid-file imports (E402), and import-order errors — 55 of 71 ruff violations → plan code blocks are **never linted** by any review gate → assemble blocks into real files mentally (or lint them) before declaring a plan verified. Filed agent-infra#904.
[process]: A reviewer that declines to say `NO ISSUES FOUND` **cannot** be recorded as `clean`, even after the issues are fixed → recording `clean` requires convergence, and fixing without re-dispatching a fresh reviewer is a bypass, not a review → record the gate RED, document the cycle log and the open issue, and proceed.
[process]: A "kill-switch" keyed on a **proxy metric** produces a "neither fires nor clears" outcome that no skill defines a disposition for → the metric could not have decided the question, so the result is a mis-keyed gate, not an inconclusive one → when a gate's outcome is undefined, check *whether the measured quantity could move the decision* before inventing a disposition. Filed agent-infra#905.
[git]: A commit message passed through the shell on the command line risks backtick/`$VAR` expansion, and `-m` cannot carry newlines written as `\n` escapes (a literal newline in `-m` does work, and repeated `-m` flags build paragraphs) → both routes corrupt or limit the message → write it with the `write` tool to `/tmp/commit-msg-<branch>.md` and use `git commit -F <file>` with a long timeout.
[git]: The main checkout **blocks edits** (`⛔ File edits in the main checkout are blocked`) → parallel agents could overwrite each other → create an isolated worktree via `bash scripts/checkout-hygiene/hub-worktree.sh "<branch>"`.
[review]: Every prose-only review round found wording problems; every round that actually **executed** something found behaviour problems → a reviewer that only reads is not a verification → require the reviewer to run the code, not just read it. Filed agent-infra#806.
[deploy]: A Cloudflare Pages project with **no Function for a path** answers 200 with the SPA shell → a status-only probe reads a wrong-origin or missing-route deployment as healthy (this is how the BFF's misplacement stayed invisible) → probe the route's BEHAVIOUR (`/auth/start` → 302, `/api/session` → 401, `/welcome` → 302), never a bare 200.
[e2e]: `wrangler pages dev .` serves the **SOURCE** tree, not `dist/` → pages that live in `public/` are not at their production paths, so Pages serves the SPA shell and e2e assertions silently check `index.html` (Wrangler resolves `functions/` against the CWD, not the directory argument) → serve the BUILT root so the paths under test are the deployed ones.
[test]: The pytest session redirects `TMPDIR` to a private per-session root (`tests/_tmpdir_isolation.py`, #3752) → `tempfile.gettempdir()` is **cached**, so setting `os.environ["TMPDIR"]` alone is ignored by an already-primed process, and host-global coordination paths (`ACTIVE_SUITES_DIR`) would silently follow the redirect → set `tempfile.tempdir` *and* the env, keep host paths addressable via a host-pinned accessor, and route discovery through the scoped root (an in-process `os.scandir` of the shared temp dir raises `SharedTmpdirScanError`).
[af-unix]: The private session temp root adds 12 bytes to every scratch path → AF_UNIX `sun_path` is a hard **kernel** cap (< 104 on macOS, not 108): a child whose `TMPDIR` nests one level deeper reached 108 bytes and the redislite server died with `unix socket path too long … orphan spawn failed: ''` → keep a socket-binding child's `TMPDIR` ≤ 78 bytes (its bind path is `TMPDIR + "/tmpXXXXXXXX/redis.socket"`, 25 bytes — redislite's autogen dir uses the default `tmp` prefix), and assert the arithmetic in the fixture so a longer host tempdir fails by name. Note `/var/folders/...` vs realpath `/private/var/folders/...` are **two spellings of the same dir**, and `tempfile.gettempdir()`'s own raw fallback (`/tmp` vs `/private/tmp`) is a third — a guard matching only realpaths fails open on the raw ones.
