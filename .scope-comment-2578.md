## Scope direction — decided 2026-09-09 (human approval gate)

Problem-diverge (2 agents) + problem-converge (2 independent agents, converging on the same corrected framing at confidence 70/82) found the issue's framing survives contact with the code in its *measurement* intent but needed three corrections before a run is honest. The scoped plan is `docs/plans/2026-09-09-2578-temporal-measurement.md` (uncommitted on `feat/2165-connected-assembly` — a later commit lands it once approved).

### 1. What we found (plain language)

- **The "0/13" is not something we can reproduce — no committed artifact pins the 13.** Every committed report in the repo root is an n=1 *mock* mini-run of a non-temporal question (`mini_ie_user_001`). The deep diagnosis ("gold at ranks 48–68") lives only in an uncommitted /tmp synthesis. So the honest unit of measurement is not "the 13" — it is the **full 133-question temporal class** that the committed census (`tests/_assembly_census.json`) already enumerates, with the **55-question deterministic-fireable subset** (ordering/compare 34 + interval 19 + current-state 2 = 41%) as the analysis denominator. We say this plainly: the original claim is treated as *not reproducible from committed artifacts* and superseded by a fresh committed measurement — we do not chase a ghost denominator.
- **The census bounds what widening can possibly fix.** Only ~55/133 (41%) of the temporal class is deterministically fireable by the shapes the assembler lane targets. The other ~59% (ago-relative 31, frequency/count 12, duration-state 7, relative-date-lookup 6, nary-ordering 4, other 6, pattern/recurring 1, offset-comparison 1) is *not* an admission problem any knob sweep can fix — it is baseline-registered, and follow-up issues get filed for it (R15 trigger). Recency (10 Qs) is governed by a different knob family.
- **Admission geometry is a hypothesis to test, not a settled diagnosis — and the committed record says the READER may be the real ceiling.** The eval's own history (R5: 9/18 temporal losses were reader *refusals* even when all gold evidence was in context; the #1987 runbook: "the model is the binding constraint" on arithmetic/ordering/derived answers) documents conversion failures *with evidence admitted* — the opposite of an admission failure. So the measurement is designed as a **2×2 attribution** (admission × conversion per question), not a bare accuracy delta: widening that lifts admission but not conversion is a decision-grade finding (conversion-bound), not a failed arm. We pre-register that null before any arm runs.
- **The knobs themselves have reach ceilings we pre-register.** `tr_top_k` widening admits roughly the top 12→20–24 pool ranks (further trimmed by the 8k-token budget — 20 vs 24 are near-duplicates). The C2 evidence-boost is a position-ceiling promotion that can't reach deep gold on these derived-answer questions. Only the applied-rerank arm (pool 40→120 + cap 2→3 + scorer) can promote deep gold — and it confounds pool × ordering × scorer, so it's reported with a pool-only "isolation" leg that separates depth from reordering. Every arm carries a documented reach statement before it runs; a null is a pre-registered outcome, never a failed arm.

### 2. What will be measured (the committed deliverable)

Per-question, per-arm, committed outcome rows over the census enumeration, with every miss classified as:
- **Admission failure** — gold evidence absent from the effective reader context (we capture the *actual* post-cap reader context in the loop; the id-level set is not reconstructable from today's committed reports, so this needs a small instrumentation change), with the derivable sub-classes (outside rerank-depth / dropped by item-cap / undated-gold).
- **Conversion failure** — gold present but the pinned reader got it wrong, split into **refusal** vs **wrong** (tracked separately, never merged), with the reader held constant across arms (same model/prompt/temperature, fingerprint-isolated) and stub-reader runs pre-registered as "conversion not measured" (ABSTAIN — never reported as evidence).
- The runbook gate records three pre-registered branches: widening lifted accuracy → attribute to admission; residual is refusal/wrong on *admitted* gold → conversion-bound (with an honest caveat that "wrong" here is mostly reader arithmetic/derivation limits — the assembler's ordering-of-evidence justification is *not* asserted from the 2×2; a named qualitative pass would isolate it); gold unreachable under every widening → structural-path evidence for the assembler.
- **v2-lane structural probe** (staged): does the v2 lane actually create the Objects + aboutObject + dated events the assembler would walk, for the gold turns of the 55? (Substrate *existence* only — not an assembler admission run, which stays #2165's synthetic-graph acceptance.)

### 3. The ablation (pre-registered, per the issue's Indicator 2)

A-default baseline → `tr_top_k` 16/20/24 (with reader-refusal tracking and an R5 rollback guard: a per-arm refusal-rate ceiling tied to context-token growth; breach = flagged rollback-candidate) → C2 evidence-boost ON → applied rerank (pool 40→120, per-session cap 2→3) + pool-only isolation leg → cap-3-only. Reader/judge/prompt identical across all arms; every arm fingerprint-isolated (one verified gap — `tr_top_k` was missing from the run fingerprint, so a 12↔16 cross-arm resume could silently blend denominators — is fixed in scope).

### 4. Honest limitations (what this will NOT prove)

- It will not resurrect the 0/13 (nothing committed can).
- It will not prove the assembler "fixes" temporal reasoning — if conversion binds, that's a reader-model question (#2013) plus a follow-up qualitative pass, not this measurement's claim.
- It will not fix the ~68 non-fireable census classes (filed as follow-ups with the census as trigger).
- Oracle-tier comparison is not runnable (the harness has no oracle mode) — pre-registered omission.
- The 55-Q × 7-arm sweep + 133-Q baseline + staged v2 probe is a bounded real-reader run budget; the v2 probe's dominant cost is LLM extraction over ~40–61 sessions/question, so it is staged (wave-1 ~15 Qs with a saturating stop).
